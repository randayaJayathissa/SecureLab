# SecureLab

A progressive Linux server security and monitoring
homelab built to explore system administration,
network security, security monitoring and DevOps.

## Objectives

- Deploy and administer a Linux server
- Understand network exposure and service configuration
- Harden SSH and host firewall rules
- Analyze system and application logs
- Automate security auditing using Bash and Python
- Containerize services with Docker
- Integrate security checks into CI/CD
